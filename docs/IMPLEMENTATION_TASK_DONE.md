## ✅ 달성된 목표

## 📋 구현 요약

### 핵심 구성 요소 (footnote_manager.py)
1. **데이터 구조**
   - `MatchCandidate`: matched_ref, confidence, source, citation_type, doi, preview
   - `MatchResult`: best_match, candidates 리스트

2. **점수 매기기 시스템**
   - `_calculate_similarity()`: difflib.SequenceMatcher 사용
   - `_score_match()`: 가중치 매기기 - 제목(0.4) + 저자(0.4) + 연도(0.2)
   - 연도 매칭: 정확한 일치 = 1.0, 일치하지 않음 = 0.0

3. **자동 매칭 로직**
   - **메모리-first 흐름**: SHORT → 메모리 반복 확인 → FULL 처리
   - **반복 인용**: 단일 고신뢰도 후보 반환 (사용자 선택 불필요)
   - **전체 인용**: 로컬 변형 생성 → 점수 매기기 → 상위 3위 후보 반환
   - 로컬 변형: 원본 형식, et al. 변형, 제목 인용 변형

4. **부가 기능**
   - BibTeX 내보내기 기능 추가
   - 기존 기능 및 GUI 호환성 완전 유지
   - 스레드 안전성 유지 (기존 큐 기반 디스패처 활용)

- **전체 인용 처리**: 세 가지 형식 후보 생성 후 신뢰도 순 정렬 환원
- **로컬 변형 생성**: 적절 시 "et al." 및 제목 인용 옵션 생성
