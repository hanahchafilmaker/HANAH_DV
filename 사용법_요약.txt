# 논문 자동 생성 시스템 - 각주 기반 워크플로우 사용법

## 개요
기존의 CSV 매칭 표 방식을 대체하는 새로운 각주 관리 시스템입니다.
Word 문서의 각주를 직접 추출 → 편집 → 참고문헌 자동 생성 → 최종 문서에 반환하는 전체 파이프라인을 제공합니다.

## 구성 파일
1. `main_gui.py` - 메인 인터페이스
2. `footnote_manager.py` - 각주 추출, CSV 생성, bibliography 생성, DOCX 업데이트 기능
3. `footnote_editor.py` - 독립적인 각주 편집기 (선택 사항)
4. `engine.py` - 기존 스타일 적용 함수 재사용
5. `create_cover.py`, `create_approval.py` - 표지 및 인준지 생성 (변경 없음)

## 워크플로우

### 1. Word 문서 선택 및 각주 추출
- 메인 GUI에서 "DOCX 파일 선택" 버튼으로 작업할 Word 문서를 선택
- "각주 편집기 열기" 클릭 시 문서에서 모든 각주를 추출하여 편집 창 표시

### 2. 각주 편집
좌측: 원본 각주 (읽기 전용)
우측:
  - 참고문헌 필드: 학술적인 참고문헌 형식으로 편집 (예: "저자. '제목'. 출판사, 연도.")
  - 매칭 체크박스: 이 각주를 참고문헌에 포함할지 여부

### 3. 참고문헌 생성 및 미리보기
- "참고문헌 미리보기" 버튼으로 현재 매칭된 각주로부터 참고문헌 목록 생성
- 중복 제거됨 (같은 참고문헌은 하나만 포함)

### 4. 최종 문서 생성
- "참고문헌 생성 및 최종 문서 만들기" 버튼 클릭
- 또는 편집기에서 "CSV 저장" → 메인 GUI에서 최종 생성 버튼 사용
- 결과:
  - 본문 스타일 적용 (Normal: 22pt, Heading1: 32pt, Heading2: 28pt)
  - 문서 끝에 "참고문헌" 제목과 함께 생성된 참고문헌 목록 추가

## 주의 사항
- 입력된 각주 텍스트는 원본 형태로 보존됩니다 (fn_text 컬럼)
- 수정된 참고문헌 텍스트는 matched_ref 컬럼에 저장됩니다
- 상태(status) 컬럼에 "✅ 매칭"이 들어간 행만 참고문헌에 포함됩니다
- 파일은 UTF-8-SIG 인코딩으로 저장되어 엑셀에서 한글 깨짐 없이 열 수 있습니다

## 독립 실행형 편집기 사용법
- `footnote_editor.py`를 직접 실행하여 독립적인 각주 편집기 사용 가능
- DOCX 불러오기 → 편집 → CSV 저장 → 참고문헌 생성 → DOCX에 반영 모든 기능을 일괄 처리

## 기존 시스템과의 호환성
- 기존 `각주_참고문헌_매칭표.csv` 형식과 호환 (추가 컬럼: fn_type, status)
- 엔진의 스타일 적용 기능은 그대로 재사용
- 표지 및 인준지 생성 기능은 변경 없이 사용 가능
