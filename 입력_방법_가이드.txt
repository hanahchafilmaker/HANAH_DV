각주_참고문헌_매칭표.csv 입력 방법 단계별 가이드

=== 1. 파일 열기 방법 ===

옵션 A: 엑셀/스프레드시트 사용 (추천)
1. 각주_참고문헌_매칭표_템플릿.csv 파일을 더블클릭
2. 또는 엑셀 실행 → 파일 열기 → 위 템플릿 파일 선택
3. 칼럼별로 neatly 정렬된 테이블 형태로 보임

옵션 B: 메모장/코드 편집기 사용
1. 템플릿 파일을 우클릭 → "연결 프로그램" → 메모장 또는 VS Code 선택
2. 각 줄이 하나의 행을 나타냄, 셀 사이는 쉼표(,)로 구분

=== 2. 각 칼럼 설명 및 입력 예시 ===

칼럼명 | 입력 내용 | 예시
-------|----------|------
fn_num | 각주 순번 (숫자만) | 1, 2, 3, ...
fn_type | 각주 유형 (다음 중 선택) |
       | - 출처: 책, 논문, 웹페이지 등 참고문헌 | "출처"
       | - 설명주: 내용 설명이나 부가 정보 | "설명주"
       | - 재인용: 다른 논문에서 인용한 내용 | "재인용"
       | - 기타: URL, 캡처 등 | "URL", "캡처"
fn_text | 원본 각주 내용 그대로 복사 | "Susan Sontag, 'The Decay of Cinema,' The New York Times, February 25, 1996..."
matched_ref | 학술적인 참고문헌 형식으로 변환 | "Sontag, Susan. 'The Decay of Cinema.' The New York Times, February 25, 1996. https://..."
status | 매칭 상태 (작성 중이면 비워두세요) |
       | - 매칭 완료: "✅ 매칭" 입력
       | - 미매칭: 비워두거나 "❌ 누락"
       | - 불필요 항목: "⬜ 불필요" (캡처, URL 등)

=== 4. 입력 팁 ===

A. 복사&붙여넣기 효율화
1. 원본 논문에서 각주 텍스트를 복사 → fn_text에 붙여넣기
2. 같은 내용에서 참고문헌 형식으로 수정 → matched_ref에 붙여넣기
   (예: 저자 순서 바꾸기, italics 제거, URL 형식 통일 등)

B. 상태 관리
- 작업 중: status 칼럼을 비워두세요
- 한 행 완료: "✅ 매칭" 입력
- 보류 중: "⏳ 검토중" 또는 비워둠
- 제외 대상: "⬜ 불필요" (이건 참고문헌에 들어가지 않음)

C. 특수 내용 처리
- 웹페이지: 접근일 반드시 포함 (예: "접속일: 2025.10.11.")
- 논문: 권/호, 페이지 포함
- 책: 출판사, 연도 포함
- 재인용: 원문 출처를 matched_ref에 기록

=== 5. 완성 후 검증 ===

1. 모든 필수 행 입력 완료
2. status에 "✅ 매칭"이 있는 행만 확인
3. fn_text와 matched_ref 내용이 대응되는지 시각적으로 확인
4. 파일을 저장하고 기존 프로그램을 실행해서 참고문헌이 제대로 생성되는지 테스트

=== 6. 파일 저장 주의사항 ===

- UTF-8 인코딩으로 저장해야 함 (엑셀은 보통 자동 처리)
- 메모장으로 저장할 때 "인코딩: UTF-8" 선택
- 파일 이름은 반드시 "각주_참고문헌_매칭표.csv" 로 유지
- 템플릿파일은 그대로 두고 새 파일로 작업하거나上面のように上書き保存しても構いません

これで入力方法の説明は終わりです。一つずつ丁寧に入力すれば、あとはプログラムが自動で処理してくれます。
